# -STM32-Blue-Pill-Distance-Measurement-System
Built a distance measurement system using STM32F103C8T6 (Blue Pill). HC-SR04 measures distance via time-of-flight, while DHT11 provides temperature/humidity for sound-speed compensation. A 16×2 I2C LCD displays live distance, temp, humidity, and status. Developed in STM32CubeIDE using HAL.
